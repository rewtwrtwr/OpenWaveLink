# Спецификация системы управления, горячих клавиш и игрового оверлея для Windows 11

Данный документ описывает нативную подсистему взаимодействия пользователя с аудиомикшером **OpenWaveLink** в среде операционной системы **Windows 11**.

В проекте OpenWaveLink полностью исключена зависимость от проприетарного оборудования (Stream Deck и внешних контроллеров). Вся система управления спроектирована как органичная часть Windows 11: легковесный всплывающий микшер в системном трее, глобальные аппаратные горячие клавиши, плавающий игровой HUD-оверлей поверх полноэкранных приложений и интеграция с мультимедиа-сервисами Windows (SMTC).

---

## 1. Архитектурная концепция управления под Windows 11

Пользователю Windows 11 не требуется покупать дорогостоящие внешние USB-панели управления, чтобы мгновенно заглушить микрофон, изменить баланс между игрой и Discord или подстроить громкость музыки. 

Управление OpenWaveLink в Windows 11 опирается на четыре нативных механизма:
1. **Быстрый всплывающий микшер трея (Windows 11 Tray Flyout)**: доступ по клику в правом нижнем углу панели задач рядом с системными часами.
2. **Глобальные горячие клавиши (Global Hotkeys)**: низкоуровневые хуки Win32 API для регулировки громкости и мгновенного мутирования без потери фокуса из игр.
3. **Плавающий полупрозрачный HUD-оверлей (DirectX/DWM Overlay)**: визуальная индикация шкал громкости и статуса микрофона поверх любых игр и 3D-приложений.
4. **Интеграция с мультимедиа-клавишами (SMTC)**: привязка физических кнопок громкости мультимедийных клавиатур и ноутбуков к конкретным виртуальным каналам.

## 2. Интеграция в системный трей Windows 11 (Taskbar Flyout)

Штатный регулятор громкости Windows 11 (Win + A / Quick Settings) не позволяет раздельно управлять громкостью стрима, записи и мониторинга. OpenWaveLink встраивает в системный трей кастомное всплывающее окно (Flyout), оформленное в строгом соответствии с гайдлайнами **Windows 11 Fluent Design**.

### 2.1. Позиционирование и анимация
- При клике левой кнопкой мыши по иконке OpenWaveLink в трее вызывается функция `Shell_NotifyIconGetRect`, определяющая точные координаты иконки на панели задач.
- Окно позиционируется ровно над панелью задач с отступом 12px и закругленными углами (`DWMWA_WINDOW_CORNER_PREFERENCE = DWMWCP_ROUND`).
- Окно открывается с плавной анимацией скольжения и прозрачности (DirectComposition Slide & Fade-in).
- При клике вне области окна или потере фокуса (`WM_ACTIVATE / WA_INACTIVE`) окно мгновенно и плавно закрывается без мерцания.

### 2.2. Визуальный стиль Fluent Design
- **Материал фона**: нативный эффект **Mica Alt** (`DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_TABBEDWINDOW`) или **Acrylic**, подстраивающийся под светлую/темную тему Windows 11 и акцентный цвет пользователя (Accent Color).
- **Слайдеры громкости**: горизонтальные тонкие ползунки с плавной кинетикой, значением в процентах и логарифмической шкалой dB.
- **Индикаторы активности**: встроенные прямо в слайдеры микро-полоски пиковых уровней (Peak Meter), позволяющие сразу видеть, какой канал издает звук.
- **Быстрый селектор вывода**: выпадающее меню со списком подключенных наушников и динамиков (WASAPI Endpoints) для переключения мониторного микса в один клик.

## 3. Система глобальных горячих клавиш (Global Hotkeys)

Для управления звуком в динамичных играх (CS2, Dota 2, Call of Duty, Cyberpunk 2077) пользователь не должен сворачивать окно игры. OpenWaveLink реализует двухуровневую систему перехвата клавиатурного и мышиного ввода.

### 3.1. Уровень 1: Стандартные хоткеи (Win32 `RegisterHotKey`)

Используются для глобальных комбинаций клавиш-модификаторов (`Ctrl`, `Alt`, `Shift`, `Win`) и обычных кнопок:

| Действие | Комбинация по умолчанию | Описание |
|---|---|---|
| **Mute Mic** | `Ctrl + Shift + M` | Мгновенный аппаратный мут микрофона (с индикацией в HUD) |
| **Push-to-Talk / Mute** | `Caps Lock` / `F13` | Активация микрофона только при удержании |
| **Mute Music** | `Ctrl + Alt + M` | Быстрое отключение музыки при начале важного игрового раунда |
| **Game Volume Up** | `Ctrl + Alt + Up` | Увеличение громкости игрового канала на $+2\%$ |
| **Game Volume Down** | `Ctrl + Alt + Down` | Уменьшение громкости игрового канала на $-2\%$ |
| **Voice Chat Focus** | `Ctrl + Alt + D` | Приглушение всех каналов кроме Discord на $-12$ dB (Ducking) |
| **Toggle HUD Overlay** | `Ctrl + Shift + O` | Включение/отключение постоянного отображения игрового HUD |

### 3.2. Уровень 2: Низкоуровневые хуки (`WH_KEYBOARD_LL` и `WH_MOUSE_LL`)

Win32 `RegisterHotKey` не поддерживает колесико мыши и боковые кнопки (Mouse 4 / Mouse 5). Для них OpenWaveLink использует специализированный поток с низкоуровневыми хуками Windows:

1. **Регулировка громкости колесиком мыши (Scroll-Wheel Volume)**:
   - При удержании модификатора (например, `Alt + Колесо мыши`) перехватывается сообщение `WM_MOUSEWHEEL`.
   - Происходит плавная регулировка громкости того канала, который назначен приоритетным в текущем профиле (или сфокусированного приложения).
   - Если курсор мыши находится над панелью задач Windows 11, прокрутка колесика плавно меняет общий уровень мастер-микса.
2. **Кнопки мыши для Push-to-Mute**:
   - Перехват `WM_XBUTTONDOWN` / `WM_XBUTTONUP` для использования боковых кнопок мыши в качестве аппаратного переключателя микрофона с нулевой задержкой (< 1 мс).

```rust
// Пример безопасного низкоуровневого хука мыши в Rust (owl-controls)
unsafe extern "system" fn mouse_hook_proc(n_code: i32, w_param: usize, l_param: isize) -> isize {
    if n_code >= 0 && w_param == WM_MOUSEWHEEL as usize {
        let mouse_hook = *(l_param as *const MSLLHOOKSTRUCT);
        let is_alt_pressed = (GetAsyncKeyState(VK_MENU) as u16 & 0x8000) != 0;
        
        if is_alt_pressed {
            let delta = (mouse_hook.mouseData >> 16) as i16;
            let step = if delta > 0 { 0.02 } else { -0.02 };
            // Отправка неблокирующего события в диспетчер каналов
            CHANNEL_DISPATCHER.adjust_focused_channel_volume(step);
            return 1; // Поглощаем событие колесика, чтобы игра не зумировала камеру
        }
    }
    CallNextHookEx(std::ptr::null_mut(), n_code, w_param, l_param)
}
```

## 4. Плавающий игровой HUD и экранный оверлей (In-Game Overlay)

При регулировке звука с клавиатуры или мыши пользователь должен визуально видеть текущий уровень, не покидая полноэкранный игровой процесс.

### 4.1. Архитектура оверлея DirectComposition Topmost

OpenWaveLink создает специализированное окно DWM (Desktop Window Manager):
- **Стили окна**:
  - `WS_EX_TOPMOST`: всегда поверх всех окон.
  - `WS_EX_TRANSPARENT`: клики мыши проходят сквозь окно в игру (Click-through).
  - `WS_EX_LAYERED`: поддержка альфа-канала каждого пикселя.
  - `WS_EX_NOACTIVATE`: окно никогда не перехватывает фокус ввода у игры.
- **Отрисовка**:
  - Direct2D / DirectWrite аппаратный рендеринг через DirectComposition SwapChain.
  - Нулевая нагрузка на процессор (рендеринг на GPU, < 0.2 мс на кадр).
  - Эффект размытия фона Acrylic Blur за плашкой оверлея.

### 4.2. Сценарий работы оверлея (HUD Flyout)
1. Пользователь нажимает `Ctrl + Alt + Down` в полноэкранной игре.
2. В верхнем левом углу или по центру сверху экрана плавно появляется аккуратная карточка оверлея (Fluent HUD).
3. Карточка показывает название канала (например, `[🎮 Game Audio]`), шкалу громкости и числовой процент (`72%`).
4. Если задействован микрофон или включен Mute, иконка подсвечивается ярким цветом (красный перечеркнутый микрофон при муте).
5. Если в течение 2.0 секунд новых нажатий не поступало, оверлей плавно растворяется (Fade-out за 250 мс).

```
   +-----------------------------------------------------------+
   |   🎮 Game Audio                   72%  [-1.8 dB]          |
   |   ============================o---------                  |
   +-----------------------------------------------------------+
                 (Плавающий HUD поверх игры в 4K)
```

## 5. Интеграция с мультимедиа-клавишами Windows (SMTC)

Клавиатуры современных ПК и ноутбуков оснащены выделенными мультимедиа-кнопками:
- `Volume Up`, `Volume Down`, `Volume Mute`
- `Media Play/Pause`, `Next Track`, `Previous Track`

В стандартной Windows эти кнопки жестко привязаны к глобальному общему выходу ОС. В OpenWaveLink реализована интеграция с **System Media Transport Controls (SMTC)** через WinRT API (`ISystemMediaTransportControlsInterop`):

### 5.1. Умное перенаправление мультимедиа-кнопок
- **Режим «Фокус на игру»**: мультимедийные клавиши регулируют не общую громкость Windows, а только виртуальный канал текущей активной игры.
- **Режим «Фокус на медиа»**: клавиши Play/Pause/Next/Prev перенаправляются в плеер (Spotify, Яндекс.Музыка, AIMP), даже если плеер находится в фоновом режиме, а пользователь играет в полноэкранную игру.
- **Мгновенный аппаратный Mute**: нажатие системной клавиши Mute может быть настроено как мут микрофона стримера, а не наушников.
