# Спецификация интерфейса OpenWaveLink (Pixel-Perfect Wave Link 3.0 Matrix UI)

Данный документ представляет собой эталонную визуальную и функциональную спецификацию графического интерфейса **OpenWaveLink**, полностью копирующую стиль, палитру, компоновку и динамическую механику **Elgato Wave Link 3.0 (Beta)** под **Windows 11**.

---

## 1. Цветовая палитра и стилистика (Серый матовый минимализм, БЕЗ НЕОНА)

Интерфейс строго повторяет премиальный, сдержанный профессиональный стиль Elgato Wave Link:
- **Никаких ядовитых неоновых цветов** (отказ от кислотно-зелёного, кислотно-голубого, неоново-фиолетовых свечений и градиентов).
- Спокойная, глубокая тёмно-серая / матовая графитовая палитра с мягкими приглушёнными акцентами.

### Цветовые токены:
- **Базовый фон окна (Canvas)**: `#16141a` .. `#18161e` (глубокий сдержанный матовый графит).
- **Фон строки входного канала (Input Row)**: `#211d27` (ровный матовый темный тон).
- **Фон активной клетки матрицы (Cross-point Card)**: `#272230`.
- **Фон пустой неактивной клетки**: `#191621` (с тонкой приглушенной границей `rgba(255, 255, 255, 0.05)`).
- **Ховер пустой клетки**: появление круглой серой кнопки `(+)` с тултипом `Add channel to mix`.
- **Заголовки миксов (Mix Header Card)**: `#262130` с матовой окантовкой и радиусом скругления `8px`.
- **Индикатор прослушивания (Listening Indicator)**: тонкая матовая сиреневая полоска `#c084fc` (`height: 3px`) по верхнему краю активного микса, выбранного в селекторе `Listening to`.
- **Акцентный цвет ползунков (Thumb & Progress)**: сдержанный приглушенный сиренево-розовый `#d88be2` (круглая ручка `#d88be2`, активная часть трека `#a855f7` без свечения).
- **Неактивный трек ползунка**: темно-серый `#332d3d`.
- **Состояние MUTE**: плашка окрашивается в матовый темно-бордовый `#3a1c24` с красной рамкой `#ef4444`, иконка перечеркнутого динамика становится спокойного красного цвета.
- **Шрифт**: Windows 11 `Segoe UI Variable Text`, `Segoe UI`.
  - Заголовки категорий и списков: приглушенный нейтральный серый `#9ca3af`, 11px, `uppercase font-semibold tracking-wider`.
  - Основной текст: светло-серый `#e4e4e7`.
  - Второстепенный текст и подписи: нейтральный серый `#71717a`.

## 2. Динамическая топология матрицы: Никаких зашитых жестких колонок!

### Архитектурный принцип:
По умолчанию при первом запуске в приложении создается ровно **2 ноды**:
1. **1 Входной канал**: `System` (системный звук).
2. **1 Выходная шина (Микс)**: `Personal Mix` (звук в наушники).

Пользователь сам с нуля настраивает свою матрицу — добавляет столько входов и столько миксов-выходов, сколько ему нужно!

## 3. Компоненты интерфейса в деталях

### 3.1. Верхняя панель управления (Header Bar)
- **Слева**: 
  - Меню-бургер `☰` (Настройки, горячие клавиши, о программе).
  - Иконка и логотип `OpenWaveLink`.
  - Крупный лаконичный заголовок `Mixes`.
- **Справа (Панель мониторинга)**:
  - Селектор `Listening to [ Personal Mix  v ]` — выпадающий список, определяющий, какой именно из созданных пользователем миксов направляется на физический выход мониторинга.
  - Селектор `on [ Speakers (Sound Blaster Play! 3)  v ]` — выпадающий список физических аудиоустройств вывода Windows 11 (наушники, динамики, внешняя звуковая карта).
  - Иконка экспорта / шаринга конфига `[^]`.
  - Иконка развертывания/открепления окна `[↗]`.

---

### 3.2. Левая колонка: Входные каналы (Inputs)
Каждая строка входа представляет собой аккуратную плашку с фиксированной высотой (~56px):
1. **Иконка источника**:
   - Реальная иконка процесса (извлекается из `.exe` игры/программы в Windows 11).
   - Или системная иконка (микрофон для физических входов, монитор для System).
2. **Имя канала**:
   - Например: `System`, `Spotify`, `Microphone (fifine AM8 Pro)`.
   - Возможность двойного клика для переименования.
3. **Кнопка Master Mute канала**: иконка динамика `(🔊)`.
4. **Горизонтальный компактный слайдер Master Gain канала**: регулирует общую чувствительность входа до разделения по миксам.
5. **Кнопка VST3 эффектов `(〰️)` (Audio Wave FX)**:
   - Открывает компактную всплывающую панель со слотами VST3 плагинов (Noise Gate, EQ, Compressor).

#### Кнопка `+ Create channel` и выпадающее меню:
- **Кнопка**: аккуратная плашка с ровно одним плюсом `+ Create channel` (без дублирования `+ +`).
- **Позиционирование меню**: панель раскрывается **строго ВНИЗ** от кнопки `+ Create channel` (никогда не раскрывается вверх и не перекрывает кнопку!).
- **Размеры и скроллинг**: длинная панель (`max-height: 480px`), ширина ~360px, аккуратный тонкий темно-серый скроллбар, плавное прокручивание без обрезания контента.
- **Стилистика (Серый матовый минимализм, БЕЗ НЕОНА)**:
  - Никаких кислотно-зеленых, неоново-голубых или светящихся элементов!
  - Фон выпадающей панели: глубокий матовый графит `#201c2b` с тонкой каймой `1px solid rgba(255, 255, 255, 0.08)` и мягкой тенью.
  - Поле поиска: `🔍 Search` со спокойной серой рамкой `#3d374a` и фоном `#16131f`.
  - Заголовки категорий: приглушенный серый `#9ca3af`, 11px, `uppercase font-semibold tracking-wider`.
  - Иконки: спокойные монохромные серые `#9ca3af` или реальные системные пиктограммы.
- **ЖЕСТКИЙ ЗАПРЕТ НА МОКИ И ЗАТЫЧКИ (100% Real Windows 11 Data)**:
  - **Запрещено**: зашивать фейковые списки вроде `Counter-Strike 2`, `Discord Voice` в константах React! Если приложение не запущено — его НЕ ДОЛЖНО быть в `Active apps`.
  - **Секция `Input devices` (Микрофоны и физические входы)**: запрашивается из Windows CoreAudio через `IMMDeviceEnumerator(eCapture)` (возвращает реальные подключенные микрофоны, гарнитуры и линейные входы ПК).
  - **Секция `Active apps` (Активные процессы)**: опрашивается в реальном времени через `owl_core::enumerate_audio_sessions()` (`IAudioSessionEnumerator`). Отображаются ТОЛЬКО те программы, которые прямо сейчас воспроизводят звук на компьютере пользователя.
  - **Секция `Installed / Suggested apps` (Установленные программы)**: опрашивает зарегистрированные программы Windows 11 (через реестр `App Paths` / `Uninstall` или ярлыки). При клике по установленной программе канал создается по имени `.exe`, а при появлении звука процесс автоматически цепляется по PID.
  - **Пункт `Add empty channel >`**: создание пустого канала с возможностью задать имя вручную.
  - **Выбор аудиоустройств вывода (в модалке микса и селекторе `on`)**: запрашивается через `IMMDeviceEnumerator(eRender)` (реальные наушники, колонки, Sound Blaster, Realtek).

---

### 3.3. Столбцы: Выходные шины-миксы (Mixes)

#### Заголовок микса (Mix Column Header):
- Карточка с закругленными углами:
  - Иконка микса (наушники для Personal Mix, антенна для Stream Mix, микрофон для MicFX и т.д.).
  - Название микса (кастомное имя, задаваемое пользователем).
  - Подпись количества выходов (например, `1 output` или `2 outputs`).
  - Тонкая фиолетовая полоска `#d97ee0` по верхней кромке, если этот микс сейчас выбран в селекторе `Listening to`.
- Клик по карточке микса открывает **Модальное окно детальной настройки микса (Mix Settings Modal)**.

#### Кнопка `+` (Новый микс):
Расположена в правом краю заголовков колонок. Позволяет в один клик создать новую шину с произвольным именем (например, `Record Mix`, `Discord Feed`, `VOD Track`, `Translate Mix`).

---

### 3.4. Модальное окно настройки микса (Mix Settings Modal)
Открывается при клике на заголовок любого микса:
- **Заголовок**: редактируемое текстовое поле с именем микса (например, `Record Mix`), кнопка меню `...` и крестик `✕` закрытия.
- **Левая часть**:
  - Крупная белая или стилизованная квадратная плитка с цифрой/иконкой микса.
  - Метка `Mix volume` и горизонтальный мастер-фейдер громкости данного микса.
  - Снизу кнопка `🗑️ Delete mix` с корзиной (удаляет эту выходную шину из матрицы).
- **Правая часть**:
  - Вкладки `Audio output` и `Mix settings`.
  - Во вкладке `Audio output`: кнопка `+ Add output`. Позволяет добавить несколько физических устройств вывода для дублирования звука микса (например, отправить один и тот же Personal Mix одновременно в USB-наушники и в колонки!).
- **Снизу справа**: кнопка `Close window` с мягким сиреневым акцентом.

---

### 3.5. Клетки пересечений матрицы (Cross-Points)

Это ключевая логика подачи звука:

1. **Неактивное состояние (Канал не отправляется в микс)**:
   - Клетка пустая с темным фоном `#1a1624`.
   - При наведении курсора (Hover) по центру плавно появляется круглая кнопка с плюсиком `(+)` и всплывает подсказка: **`Add channel to mix`**.
2. **Активация**:
   - Клик по кнопке `(+)` или клетке мгновенно активирует посыл звука из данного канала в данный микс.
   - Внутри клетки появляется плашка `#2b2538`.
3. **Активное состояние (Канал отправляется в микс)**:
   - **Иконка динамика (Mute для данного микса)**: 
     - В активном состоянии: динамик белого цвета.
     - В состоянии Mute: кнопка подсвечивается темно-красным `#3d1a24` с красной рамкой, динамик становится перечеркнутым. **Звук глушится ТОЛЬКО для этого микса!** (например, Spotify заглушен для зрителей стрима, но продолжает играть в наушниках создателя).
   - **Горизонтальный слайдер Send Gain**:
     - Плавно регулирует громкость подачи канала **ТОЛЬКО для этой конкретной шины-микса** (от $-\infty$ до $+12\text{ dB}$, значение по умолчанию $0\text{ dB}$ / $1.0$).
     - Изменение громкости происходит без щелчков благодаря One-Pole сглаживателю в аудиоядре.
   - **Отключение канала от микса**:
     - Правый клик по плашке или зажатие `Alt+Click` возвращает клетку в пустое состояние (посыл отключается, ресурсы CPU на микширование не тратятся).

## 4. Виртуальные кабели в системе Windows 11

Каждый созданный пользователем входной канал или выходной микс может опционально отображаться в Windows 11 как виртуальное аудиоустройство:

1. **Входные виртуальные устройства (Virtual Render Endpoints)**:
   - Создаются через WDM WaveRT драйвер: `OpenWaveLink System`, `OpenWaveLink Spotify`, `OpenWaveLink Counter-Strike 2`, `OpenWaveLink Discord`.
   - **Удобство для пользователя**: В настройках Windows 11 или в меню игры (CS2, Discord, браузер) пользователь просто выбирает соответствующее устройство вывода, и звук автоматически попадает в нужную строку OpenWaveLink без ручного захвата по PID!
2. **Выходные виртуальные микрофоны (Virtual Capture Endpoints)**:
   - Например: `OpenWaveLink Personal Mix`, `OpenWaveLink Stream Mix`, `OpenWaveLink MicFX`.
   - Любое стороннее приложение (OBS, Discord, Zoom) может выбрать этот виртуальный микрофон для записи или голосовой связи.

## 5. Резюме для реализации в кодовой базе

1. **Фронтенд (`crates/owl-app/ui`)**:
   - Заменить жестко закодированную матрицу 8x5 на **динамический массив каналов `channels: Channel[]` и миксов `mixes: Mix[]`**.
   - Начальное состояние по умолчанию: `[ { id: 1, name: "System", type: "system" } ]` и `[ { id: 1, name: "Personal Mix", type: "monitor" } ]`.
   - Реализовать Dropdown меню `+ Create channel` со сканированием сессий через `owl-daemon`.
   - Реализовать кнопку `+` для добавления миксов и модальное окно `MixSettingsModal.tsx`.
   - Реализовать интерактивные Cross-points с состояниями Empty / Active / Muted.
   - Использовать точную цветовую гамму Wave Link 3.0 (темно-фиолетовый фон `#17141f`, карточки `#262130`, акценты `#d97ee0`, красные кнопки мута `#ef4444`).
2. **Бэкенд (`crates/owl-core` и `crates/owl-daemon`)**:
   - Поддержка динамического добавления/удаления каналов `matrix.add_channel(...)` и `matrix.remove_channel(...)` на лету.
   - Поддержка динамического создания/удаления шин миксов `matrix.add_bus(...)` и `matrix.remove_bus(...)`.
   - RPC методы: `owl.createChannel`, `owl.deleteChannel`, `owl.createMix`, `owl.deleteMix`.
