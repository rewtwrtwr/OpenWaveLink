# Сравнительный анализ функционала и план разработки OpenWaveLink для Windows 11

Данный документ содержит детальный сравнительный анализ возможностей проприетарного микшера **Elgato Wave Link 3.0** и специализированного открытого решения для Windows 11 — **OpenWaveLink**, формулирует ключевые конкурентные преимущества («Killer Features»), а также представляет поэтапную дорожную карту разработки (Roadmap) от прототипа до промышленного релиза (Production) под Windows 11.

---

## 1. Введение: Преимущества специализированного решения для Windows 11

Elgato Wave Link создавался как закрытый коммерческий продукт, искусственно ограниченный рамками экосистемы аксессуаров Elgato/Corsair. Пользователю навязывается покупка внешних аппаратных консолей Stream Deck, а сам микшер страдает от искусственных ограничений по числу каналов и миксов.

В отличие от универсальных кроссплатформенных программ, **OpenWaveLink** оптимизирован исключительно под экосистему **Windows 11**:
- **Максимальная производительность**: прямое взаимодействие с ядром Windows Audio, WASAPI Process-Loopback, планировщиком MMCSS Pro Audio и разделяемой памятью Windows без потерь на абстрактные прослойки.
- **Полная независимость от Stream Deck**: удобнейшее управление через глобальные горячие клавиши Win32, колесико мыши, всплывающий микшер в системном трее и плавающий игровой HUD-оверлей поверх игр.
- **Отсутствие искусственных ограничений**: неограниченное число каналов и миксов, поддержка любых микрофонов и VST3-плагинов.

## 3. Ключевые преимущества (Killer Features) OpenWaveLink для Windows 11

### 3.1. Полный отказ от Stream Deck: Управление в играх на кончиках пальцев
Вам больше не нужно тратить 150–250$ на отдельный кнопочный пульт:
- **Глобальные горячие клавиши**: настраиваемый Mute микрофона (`Ctrl+Shift+M` или боковая кнопка мыши `Mouse 4`) с тактильной отсечкой и нулевой задержкой.
- **Плавная регулировка колесиком мыши**: зажмите `Alt` и крутите колесико мыши — громкость игры или музыки плавно меняется на лету.
- **Всплывающий плавающий HUD**: при регулировке в верхнем углу экрана плавно появляется стильный полупрозрачный индикатор с процентами и шкалой, растворяющийся через 2 секунды. Вы всегда видите точный уровень звука, не выходя из матча.

### 3.2. Всплывающий микшер панели задач (Flyout Tray Mixer)
Вместо того чтобы держать открытым тяжелое окно микшера или сворачивать игру на рабочий стол:
- Кликните по иконке OpenWaveLink в правом нижнем углу Windows 11 (рядом с часами).
- Мгновенно открывается аккуратный всплывающий пульт с закругленными углами и фоном Mica Alt.
- Доступны все основные каналы, индикаторы пиков и быстрое переключение между наушниками и колонками.

### 3.3. Zero Artificial Limits: 32+ каналов и неограниченные миксы
В коммерческом софте ограничение в 8 каналов и 5 миксов создано искусственно. Звуковое ядро OpenWaveLink на Rust выполняет логарифмическое суммирование 32 стереоканалов в 10 независимых миксов с использованием векторных инструкций AVX2 менее чем за 0.05 мс. Создавайте столько независимых миксов, сколько нужно вашей трансляции.

### 3.4. Умный изолированный захват звука (WASAPI Process-Loopback)
Больше не нужно мучиться с созданием десятков виртуальных кабелей в диспетчере устройств. Благодаря нативному интерфейсу Windows 11 `AUDIOCLIENT_ACTIVATION_TYPE_PROCESS_LOOPBACK`, OpenWaveLink захватывает звук напрямую из памяти процесса (например, `Discord.exe` или `Cyberpunk2077.exe`), даже если все программы в Windows настроены на одно стандартное аудиоустройство.

### 3.5. Встроенный Web Remote Control по локальной сети
Закрепите смартфон на штативе или положите планшет рядом с клавиатурой:
- Встроенный веб-сервер выдает QR-код для быстрого подключения.
- Сенсорные фейдеры на экране смартфона позволяют плавно регулировать громкость пальцами во время стрима через обычный браузер по Wi-Fi.

### Фаза 1: Концепт и прототип веб-интерфейса (Завершено)
- [x] Реализация матричного интерфейса (CSS Grid Matrix) в стилистике профессионального аудио-пульта.
- [x] Браузерный симулятор звукового движка на базе Web Audio API.
- [x] Программный алгоритм OpenClipguard 2.0.
- [x] Автоматизированный тестовый набор из 21 теста.

### Фаза 2: Нативное звуковое ядро Windows 11 (Q1 2027)
**Цель**: Бескомпромиссная стабильность и работа в реальном времени с наивысшим приоритетом ОС.
- [ ] Крейт `owl-core`:
  - Реализация Realtime Audio Loop с буферизацией 64–256 сэмплов при 48 кГц (задержка < 3 мс).
  - Регистрация в планировщике `AvSetMmThreadCharacteristicsW("Pro Audio")`.
  - Векторизованный OpenClipguard 2.0 на AVX2.
- [ ] Крейт `owl-backend-wasapi`:
  - Захват звука запущенных процессов через `AUDIOCLIENT_ACTIVATION_TYPE_PROCESS_LOOPBACK`.
  - Вывод мастер-миксов в аппаратные WASAPI-устройства (наушники, динамики, HDMI).
  - Драйвер виртуального аудиокабеля WDM WaveRT (Sysvad).
- [ ] Хостинг VST3-плагинов:
  - Интеграция `nih-plug` со сканированием `%COMMONPROGRAMFILES%\VST3`.
  - Запуск VST-плагинов в изолированном процессе воркера (защита от падений).

### Фаза 3: Система управления, оверлей и трей (Q2 2027)
**Цель**: Удобное управление звуком вслепую во время игр.
- [ ] Крейт `owl-controls`:
  - Глобальные горячие клавиши через Win32 `RegisterHotKey`.
  - Низкоуровневые хуки `WH_KEYBOARD_LL` и `WH_MOUSE_LL` (Alt + ScrollWheel для регулировки громкости).
  - Поддержка боковых кнопок мыши для Push-to-Mute микрофона.
- [ ] Плавающий HUD-оверлей поверх игр:
  - Topmost Layered окно DirectComposition с аппаратным ускорением GPU.
  - Плавное появление и затухание при изменении громкости с клавиатуры.
- [ ] Всплывающий микшер трея (Flyout):
  - Позиционирование по `Shell_NotifyIconGetRect` над панелью задач Windows 11.
  - Оформление с материалом Mica Alt и закругленными углами.
- [ ] Интеграция с системным микшером:
  - Вызов `IAudioPolicyConfig` для назначения приложений на каналы в один клик.

### Фаза 4: Десктопная сборка и высокоскоростной IPC (Q3 2027)
**Цель**: Легковесное приложение (< 25 МБ) с ультра-отзывчивым интерфейсом.
- [ ] Интеграция Tauri 2.x с WebView2:
  - Нативная интеграция окна с системной темной/светлой темой Windows 11.
  - Потребление оперативной памяти < 40 МБ.
- [ ] Shared Memory IPC:
  - Именованная разделяемая память Windows (`CreateFileMappingW`).
  - Отрисовка пиковых уровней VU-метров со скоростью 60–144 FPS без нагрузки на CPU.
- [ ] Дополнительные модули:
  - Встроенный Web Remote Control (PWA) для управления со смартфона по Wi-Fi.
  - Поддержка мультимедиа-клавиш клавиатуры через Windows SMTC.

### Фаза 5: Промышленное тестирование и публикация (Q4 2027)

  - Тестирование стабильности при смене аудиоустройств, подключении Bluetooth-гарнитур и выходе из спящего режима.
- [ ] Дистрибуция:

  - Открытый репозиторий на GitHub с открытой лицензией MIT.
