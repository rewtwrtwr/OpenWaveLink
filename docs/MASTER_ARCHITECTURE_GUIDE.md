# OpenWaveLink: Полное генеральное руководство и архитектура (Windows 11 Master Guide)

## 1. Концепция и цели проекта

**OpenWaveLink** — это полностью открытый, высокопроизводительный цифровой матричный аудиомикшер для стримеров, геймеров, подкастеров и создателей медиаконтента, спроектированный **специально и исключительно под Windows 11**.

Проект призван полностью заменить и превзойти коммерческий **Elgato Wave Link 3.0**, устранив все его системные, лицензионные и аппаратные ограничения:
- **Никаких ограничений сетки**: неограниченное число программных входов (16, 32+) и виртуальных миксов (вместо жестких лимитов Elgato на 8 каналов и 5 миксов).
- **Стрим Дек не нужен**: вместо навязывания внешних аппаратных USB-панелей за 150–250$ реализовано нативное управление под Windows 11 — компактный Flyout в трее у часов с эффектом Mica Alt, глобальные хоткеи Win32, регулировка громкости колесиком мыши `Alt + ScrollWheel`, боковые кнопки для Push-to-Mute и полупрозрачный игровой HUD-оверлей поверх игр DirectX 11/12 и Vulkan.
- **Никаких лицензионных нарушений Elgato и платного VB-Cable**: входной контур работает на 100% без драйверов через официальный Windows 11 WASAPI Process Loopback по PID процесса, а выходной виртуальный микрофон реализован через открытый WDM WaveRT драйвер (лицензия MIT/MS-PL).
- **Открытый программный аналог Clipguard 2.0**: защита от клиппинга и перегрузки для **любых обычных микрофонов** (а не только фирменных микрофонов Elgato со специальными микросхемами).

## 2. Архитектура входного тракта: Бескабельный захват в Windows 11

### 2.1. Почему виртуальные кабели больше не нужны для входов
В классических версиях Windows (7, 8, ранней 10) не было API для разделения звука отдельных приложений. Elgato был вынужден создавать проприетарные входные кабели (Game, Chat, Music и т.д.).
В **Windows 11** корпорация Microsoft внедрила официальный интерфейс **Application Loopback Capture**:
- API: `ActivateAudioInterfaceAsync` с `AUDIOCLIENT_PROCESS_LOOPBACK_PARAMS` и `PROCESS_LOOPBACK_MODE_INCLUDE_TARGET_PROCESS_TREE`.
- Исполнение: **100% User-Mode**, нулевая задержка, ноль драйверов в ядре.
- Захват ведется по `TargetProcessId` (PID) процесса или группы процессов.

### 2.2. Архитектурные решения на базе открытых проектов (`win-capture-audio` / `Ayrton09`):
1. **Выживание при перезапуске игр (`Survives Application Restart`)**:
   Слушатель `IAudioSessionNotification::OnSessionCreated` на менеджере сессий `IAudioSessionManager2`. При запуске или перезапуске процесса по маске исполняемого файла (например, `cs2.exe`, `discord.exe`, `spotify.exe`) OpenWaveLink автоматически подключает захват без сброса настроек и участия пользователя.
2. **Исключающий режим захвата (`Exclude Mode`)**:
   Флаг `PROCESS_LOOPBACK_MODE_EXCLUDE_TARGET_PROCESS_TREE` позволяет захватить весь системный звук за вычетом конкретных процессов (например, захватить весь ПК, исключив Discord и плеер с авторской музыкой).
3. **Многопроцессное сведение (`Multi-process Mixing`)**:
   Объединение звука нескольких связанных процессов (например, мультиплеерный лаунчер + игра) в единую канальную полосу с выравниванием по системным высокоточным таймерам QPC.

## 3. Архитектура выходного тракта: Окончательный выбор WDM WaveRT драйвера (Вариант Б)

### 3.1. Анализ и причины выбора:
- **Вариант В (Steam Streaming Audio) — ИСКЛЮЧЁН**: Попытка использовать сторонний драйвер от Steam признана ненадежной и абсурдной. Она создает жесткую зависимость от стороннего лаунчера, не позволяет кастомизировать имена устройств и несет риск поломки при автообновлениях клиента Steam.
- **Вариант А (USB/IP с родным `usbaudio.sys`) — ОТКЛОНЁН**: Эмуляция USB-шины накладывает системные задержки изохронных транзакций USB (5–12 мс), повышает нагрузку на процессор и приводит к звукам отключения устройств при перезапуске приложения.
- **Вариант Б (WDM WaveRT на базе Microsoft Sysvad / MikeTheTech MIT) — ОКОНЧАТЕЛЬНО УТВЕРЖДЁН**:
  1. **Нативный стандарт Windows Pro Audio**: WaveRT (Wave Real-Time) выделяет непрерывный циклический DMA-буфер памяти в ядре (`KSPROPERTY_RTAUDIO_BUFFER`), к которому системный микшер `AudioDG.exe` обращается напрямую с задержкой **< 1 мс**.
  2. **Брендированные системные имена**: в INF-файле и топологии регистрируются чистые, понятные устройства:
     - `OpenWaveLink Stream Mix (Записывающее устройство / Микрофон)`
     - `OpenWaveLink MicFX (Обработанный чистый голос)`
     - `OpenWaveLink Aux Mix`
  3. **100% открытый код**: базируется на коде Microsoft Sysvad (MS-PL) и `Virtual-Audio-Driver` (MIT). Для Windows 11 используется процедура бесплатной автоматической подписи **Microsoft Attestation Signing**.
  4. **Надежность**: устройства остаются активными в системе, даже если графический интерфейс OpenWaveLink закрыт или перезапускается.

### 3.2. Вывод в OBS Studio через Shared Memory (Zero-Driver):
Для передачи звука в OBS Studio виртуальный кабель не нужен вовсе. OpenWaveLink предоставляет плагин `obs-openwavelink-source.dll`, считывающий PCM сэмплы из системной разделяемой памяти Windows (`CreateFileMappingW`) с задержкой **< 0.1 мс**.

## 4. Сигнальный тракт, OpenClipguard 2.0 и хостинг VST3

### 4.1. Порядок DSP-обработки в канале:
```
[Вход WASAPI Loopback / Mic]
        │
        ▼
[Input Pre-Gain (+12 dBFS / -12 dBFS)]
        │
        ▼
[OpenClipguard 2.0: Lookahead Limiter (1.5 ms) + Soft Tanh Saturation]
        │
        ▼
[VST3 Inserts (Слот 1..8, Win32 HWND GUI, Out-of-process isolation)]
        │
        ▼
[Channel Mute]
        │
        ▼
[Channel Log Fader (с One-Pole сглаживанием)]
        │
        ▼
[Матрица посылов: Matrix Send Nodes -> 5 независимых шин миксов]
        │
        ▼
[Master Mix Bus FX (Эквалайзер / Компрессор)]
        │
        ▼
[Master True Peak Brickwall Limiter (4x Oversampling)]
        │
        ▼
[Выход: WDM WaveRT (Discord) / Shared Memory (OBS) / Наушники (WASAPI)]
```

### 4.2. Алгоритм OpenClipguard 2.0:
Физический Clipguard 2.0 от Elgato использует аппаратный каскад из трёх параллельных АЦП (*Stacked ADCs*), дающий 135 дБ динамического диапазона. 
В **OpenWaveLink** аналогичный защитный эффект достигается программно для любых микрофонов:
1. Запись микрофона калибруется с аналоговым запасом по перегрузке ($-12\text{ dBFS}$).
2. Двухпроходный упреждающий лимитер (Lookahead Limiter с буфером 1.5 мс) успевает плавно понизить усиление до наступления клиппинга.
3. В случае экстремального пика (> $-0.5\text{ dBFS}$) сигнал плавно насыщается через полиномиальную функцию гиперболического тангенса $\tanh(x)$, превращая резкий хрип в музыкальное аналоговое насыщение.
4. Вся внутренняя шина микшера работает в **32-bit Float Audio** (IEEE 754), гарантируя запас по перегрузке до $+770\text{ dBFS}$ внутри цифрового тракта.

## 5. Система управления под Windows 11 и Эталонный Wave Link 3.0 UI

### 5.1. Архитектура и эстетика главного интерфейса (Pixel-Perfect Wave Link 3.0):
Подробная спецификация вынесена в [**`docs/03_ui_and_control/gui_specification/WAVE_LINK_3_UI_SPEC.md`**](./03_ui_and_control/gui_specification/WAVE_LINK_3_UI_SPEC.md):
- **Сдержанная тёмно-пурпурная гамма**: фон `#17141f`, карточки `#262130`, акценты ползунков `#d97ee0`, активный Mute `#3d1a24` с красной рамкой `#ef4444`.
- **Динамическая топология (Без жестко зашитых колонок!)**:
  - По умолчанию создается ровно **2 ноды**: вход `System` и выход `Personal Mix`.
  - **Добавление входов (`+ Create channel`)**: всплывающее меню с поиском по категориям `Input devices` (микрофоны), `Active apps` (активные процессы Windows 11), `Suggested apps`, `Add empty channel`.
  - **Добавление миксов (`+`)**: добавление кастомных выходных шин (`Record Mix`, `Discord`, `Mic++`).
  - **Настройка миксов (клик по заголовку микса)**: модальное окно с общей громкостью микса, удалением и вкладкой `Audio output` (`+ Add output` для дублирования звука микса на несколько физических устройств).
- **Интерактивные кросс-поинты**:
  - Пустая ячейка при наведении показывает кнопку `(+) Add channel to mix`.
  - Клик активирует плашку со своим независимым ползунком `Send Gain` и кнопкой Mute (звук глушится ТОЛЬКО для этого микса).
- **Верхняя панель мониторинга**:
  - Селекторы `Listening to [Personal Mix v]` и `on [Speakers... v]`, с тонкой акцентной фиолетовой полоской над активным прослушиваемым миксом.

### 5.2. Нативные механизмы управления Windows 11:
1. **Taskbar Flyout (Всплывающий микшер у часов)**:
   - Клик по иконке в системном трее Windows 11 открывает компактный плавающий микшер.
   - Позиционирование через `Shell_NotifyIconGetRect`, нативный материал **Mica Alt**, скругленные углы в стиле Windows 11 Fluent Design, быстрый селектор вывода (наушники/колонки) и фейдеры громкости.
2. **Глобальные хоткеи и управление мышью**:
   - `Win32 RegisterHotKey`: настраиваемые глобальные комбинации клавиш (например, `Ctrl+Shift+M` для мута микрофона).
   - Низкоуровневые хуки `WH_MOUSE_LL`: зажатие `Alt` + вращение колесика мыши плавно меняет громкость приложения под курсором или активного канала.
   - Боковые клавиши мыши (`Mouse 4/5`) для функции Push-to-Mute.
3. **Плавающий игровой HUD-оверлей (DirectComposition Topmost)**:
   - Аппаратное полупрозрачное окно поверх полноэкранных игр в DirectX 11/12 и Vulkan.
   - При регулировке звука кратковременно отображает индикатор уровня и статус мута, плавно растворяясь через 2 секунды. Не перехватывает фокус и не сворачивает игры.
4. **Интеграция с мультимедиа-клавишами (SMTC)**:
   - Привязка физических мультимедийных кнопок громкости клавиатур к выбранному каналу OpenWaveLink.

## 6. Технологический стек реализации

- **Real-Time Audio Core (Демон)**: **Rust** (2024 edition) с крейтами `cpal`, `windows-rs`, `nih-plug` (хостинг VST3), `rtrb` (Lock-Free SPSC RingBuffer).
- **Приоритет потоков ОС**: Регистрация в **MMCSS** (`AvSetMmThreadCharacteristicsW(L"Pro Audio")`).
- **Межпроцессное взаимодействие (IPC)**:
  - *Data Plane (60–144 FPS)*: Windows Shared Memory (`CreateFileMappingW`) для мгновенного отображения уровней громкости (VU-метров) без нагрузки на процессор.
  - *Control Plane*: Локальный WebSocket JSON-RPC 2.0 (`ws://127.0.0.1:1824`) для команд и пресетов.
- **Драйвер ядра**: WDM WaveRT на базе Microsoft Sysvad (C++, WDK, лицензия MIT).
- **Desktop UI**: **Tauri 2.x** на системном движке **Edge WebView2** + **React 19**, **Tailwind CSS**, **Framer Motion**, с нативной поддержкой материалов Mica Alt и темной темы Windows 11. Дистрибутив < 25 МБ, потребление памяти < 40 МБ.
